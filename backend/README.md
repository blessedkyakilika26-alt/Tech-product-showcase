# ICT 251 - Tech Product Showcase

## Project Description

A CRUD application for managing technology products.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite
- Postman

## Features

- View all products
- View a single product
- Add a product
- Update a product
- Delete a product

## Database

Database table: products

The database stores product details and timestamps.

## Backend Setup

1. Install Node.js.
2. Open the backend directory in the terminal.
3. Run npm install.
4. Configure the environment variables.
5. Run npm start.

## API Endpoints

GET /api/products
GET /api/products/:id
POST /api/products
PUT /api/products/:id
DELETE /api/products/:id
